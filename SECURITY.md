# Security Policy

## Reporting A Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Preferred path:

- use GitHub's private vulnerability reporting for this repository if it is available in the Security tab

Fallback path:

- contact the maintainer privately through the repository owner account: <https://github.com/DanielLiszka>

Include as much detail as you can:

- affected release tag or commit
- Windows version
- GPU model and NVIDIA driver version when relevant
- reproduction steps
- impact assessment
- any logs, traces, or proof-of-concept material that helps confirm the issue

## Supported Versions

Security fixes are best-effort for:

- the latest tagged release
- the current default branch

Older tags may not receive fixes.

## Disclosure Expectations

Please keep the report private until the issue has been assessed and a fix or mitigation plan has been prepared.
