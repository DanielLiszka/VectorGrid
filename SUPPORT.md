# Support

## Where To Ask For Help

Use GitHub Issues for:

- reproducible bug reports
- scoped feature requests
- usage questions that need repository-specific answers

Before opening an issue, check:

- `README.md`
- existing open and closed GitHub Issues

## What To Include

Support requests are much easier to triage when they include:

- the exact commit or release tag
- your Windows version
- whether you are using the CPU-only, GPU (MA sweep), or GPU (kernel) variant
- your NVIDIA GPU model and driver version for GPU paths
- the exact command, workflow, or screen involved
- the full error text and any relevant logs or screenshots

## Current Support Boundaries

Support is intentionally narrow and best-effort:

- Windows x64 is the only supported public release platform
- CPU-only is the broadest compatibility lane
- GPU paths require a working NVIDIA driver and supported runtime environment
- only the latest tagged release and any immediate follow-up on the default branch should be treated as current

This repository does not currently provide a dedicated support inbox, paid support, or a guaranteed response time.
