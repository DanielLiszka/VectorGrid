The first-tier `REPO_Improvement/` tree remains the authoritative granular routing layer for current repo surfaces. This sibling tree is for larger-scope, cross-surface epic work that would be misleading to squeeze into the original `v7` catalog.

- supersede first-tier docs only when a specific epic truly replaces them; otherwise keep the first-tier docs as granular routing references
- update this README, the epic program index, the epic tracker, and the epic execution ledger together when the active epic catalog changes
