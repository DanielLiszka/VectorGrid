# Archive

This folder holds retired planning, review, prompt-pack, and tracker material that used to live in the repo root.

It also holds one-off backup assets and historical root artifacts that are not part of the active runtime or build surface.

Purpose:

- reduce root-level clutter
- keep historical implementation context available when someone explicitly needs it
- preserve the original folder names and internal relative links where practical
